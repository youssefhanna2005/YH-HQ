# YH HQ
A browser-based 3D virtual headquarters for Youssef's AI organization.

## V1
- Explorable/orbitable 3D office dollhouse
- CEO office
- Kai Havertz — Head of Sports Betting
- Pedro Neto — Fixture & Research Analyst
- Jude Bellingham — Risk & Bankroll Manager
- Strategy Room and Lounge
- Clickable employee/room status panels

Open `index.html` through a static web server. The project uses Three.js from a CDN and has no build step.

## Direction
This is the first functional shell. Next versions can add first-person WASD movement, doors, character avatars, multiple floors, persistent dashboards, betting research data and richer architecture based on the approved reference image.
